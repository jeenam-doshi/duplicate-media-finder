## DUPLICATE MEDIA FINDER

A high-performance, AI-driven cross-media duplicate detector that uses deep neural network embeddings to analyze the actual visual content of images and videos—immune to renaming, resizing, or re-encoding.

**PROJECT STRUCTURE**

| Path | Description |
| :--- | :--- |
| `finder.py` | Core AI engine (ResNet-50 feature extraction & folder profiling)[cite: 1] |
| `main.py` | Interactive CLI with smart recommendations & visual inspector[cite: 1] |
| `requirements.txt` | Project dependencies[cite: 1, 2] |
| `.gitignore` | Ignore rules for caches, venv, and local media[cite: 1] |
| `assets/demo-1.png` | Demo screenshot showing folder profiling and similarity reporting |

**TECH STACK :-**
* **Python**, **PyTorch** & **torchvision** (ResNet-50 deep feature extraction)
* **OpenCV** (Video keyframe sampling & stream analysis)
* **Scikit-learn** (Pairwise cosine similarity matrix computation)
* **Pillow & NumPy** (Image processing & matrix manipulation)

**QUICK SETUP & USAGE :-**

1. Install dependencies:  
   `pip install -r requirements.txt`[cite: 1, 2]

2. Run the application:  
   `python main.py`[cite: 1, 2]

**USAGE & THRESHOLD GUIDE :-**

* Select option `1` and drag and drop your media folder into the terminal (quotes/spaces are cleaned automatically)[cite: 1].
* Review the Folder Profile Report generated by the AI:
  1. **Mixed Media / Videos:** Recommended threshold ~ `0.80 – 0.85` (catches cross-format or varied angles)[cite: 1].
  2. **Static Images:** Recommended threshold ~ `0.90 – 0.95` (catches exact duplicates or compressed copies)[cite: 1].
* Press Enter to accept the AI recommendation or input a custom threshold value[cite: 1].
* Choose whether to open the detected duplicate groups instantly for visual inspection and clean-up[cite: 1].# duplicate-media-finder
